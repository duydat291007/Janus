One program. Three roles.

Three Janus harts run the same nine-instruction UART program. The role register is the only difference: A sends, B receives, and the witness drives nothing and checks everything. Switch to the glitch to see the checker catch a bad stop bit.

Every value on this page comes from the Janus Python model (janus.py), recorded tick by tick by demo/gen_demo.py. The chip's Verilog matches that model tick for tick on every recorded hart. A tick here is one UART step; the program uses 8 ticks per bit. What a hart drives reaches the wire on the next tick, so "driving" can lead the line by one step. Source: github.com/duydat291007/Janus.
